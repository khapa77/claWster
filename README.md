## Обзор

Клиент получает изолированный кусок кластера — CPU, RAM, storage — и управляет им самостоятельно через kubectl или web UI. Модель аналогична DigitalOcean/Hetzner Cloud, но на ARM-железе с конкурентной ценой и возможностью работы в закрытом контуре.

---

## Порог входа

**Оценка: очень высокий**

| Что нужно | Детали |
|-----------|--------|
| Железо | Уже есть: MC1 x12, HC1, RPi4 |
| ПО | Kubernetes, Prometheus, биллинг-система, клиентский портал |
| Знания | Kubernetes admin, billing systems, security, networking |
| Время до MVP | 8–16 недель |
| Стартовый капитал | Разработка биллинга и портала (~$5–20k или своими силами) |

Главные сложности:
- **Безопасность** — клиенты не должны видеть ресурсы друг друга
- **Биллинг** — точный учёт потребления в реальном времени
- **Поддержка** — клиенты деплоят сами, значит нужна документация и helpdesk
- **Uptime** — бизнес-клиенты ожидают SLA 99.9%

## Маржинальность

**Оценка: низкая**

| Статья | Детали |
|--------|--------|
| CAPEX | Железо (уже куплено) |
| OPEX | Электричество, интернет, поддержка, разработка |
| Средний чек | $20–100/мес за небольшой namespace |
| Точка безубыточности | 30–50 активных клиентов |
| Потолок маржи | Низкий — жёсткая конкуренция с крупными провайдерами |

**Проблема:** AWS/GCP/Hetzner предлагают x86-серверы по $5–10/мес. Конкурировать по цене сложно. Нужна дифференциация: ARM-нишевые задачи, privacy-first, edge computing.

**ARM-преимущество:** цена за ватт ~3x лучше x86 → при равной марже можно предложить цену ниже на 20–40%.

## Целевой клиент

**Сегмент: DevOps-команды и технические клиенты**

| Портрет | Детали |
|---------|--------|
| Кто | DevOps-инженеры, platform teams, технические стартапы |
| Задача | Дешёвый Kubernetes-кластер для CI/CD, тестирования, staging |
| Боль | Managed Kubernetes (EKS/GKE) дорого, self-hosted сложно |
| Платит | $50–300/мес, технически грамотны, цена чувствительны |
| Канал | GitHub, HackerNews, DevOps-сообщества, Reddit r/selfhosted |

**Специфические ниши:**
- **ARM-разработчики** — тестируют ARM-native приложения
- **Edge computing** — компании, которым нужна обработка данных близко к источнику
- **Privacy-first** — клиенты, которым важно что данные не уходят в AWS

## Конкуренция

**Оценка: очень высокая**

| Конкурент | Цена | Слабость |
|-----------|------|----------|
| Hetzner Cloud | €3.79/мес (2vCPU/4GB) | x86, нет ARM |
| DigitalOcean | $12/мес (1vCPU/2GB) | x86, нет ARM |
| AWS EKS | $72/мес (только control plane) | Дорого, vendor lock |
| Scaleway | €~10/мес | Есть ARM, сильный конкурент |
| Oracle Cloud Free | Бесплатно (ARM) | Бесплатно — не победить |

**Реальная стратегия выживания:**
1. Не конкурировать глобально — работать локально (регион, страна)
2. Фокус на privacy / закрытый контур (данные не покидают локацию)
3. ARM-нативные рабочие нагрузки как специализация
4. Персональный саппорт как дифференциатор

## Архитектура

```
Internet / Client
      │
      ▼
[RPi4 4GB] ── Control Plane
      │         K3s API Server
      │         Billing API (FastAPI)
      │         Client Portal (Web UI)
      │         Prometheus (metrics collection)
      │
[1Gb Switch]
      ├── [MC1 #01] ── K3s Agent (Worker)
      ├── [MC1 #02] ── K3s Agent (Worker)
      ├── ...
      ├── [MC1 #12] ── K3s Agent (Worker)
      └── [HC1]     ── Longhorn Storage

Изоляция клиентов:
├── Клиент A → namespace-a (ResourceQuota: 4CPU/4Gi/20Gi)
├── Клиент B → namespace-b (ResourceQuota: 8CPU/8Gi/50Gi)
└── Клиент C → namespace-c (ResourceQuota: 2CPU/2Gi/10Gi)

Биллинг:
Prometheus scrape → metrics DB → Billing API →
расчёт потребления → Stripe → invoice
```

## Стек технологий

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Оркестрация | K3s | Kubernetes для ARM |
| Изоляция | ResourceQuota + NetworkPolicy | Изоляция клиентов |
| Хранилище | Longhorn | Persistent volumes |
| Метрики | Prometheus + kube-state-metrics | Учёт потребления |
| Биллинг API | FastAPI (Python) | Расчёт и выставление счетов |
| Платежи | Stripe API | Процессинг платежей |
| Клиентский портал | React + FastAPI | Web UI для клиентов |
| kubectl доступ | K8s ServiceAccount + RBAC | Изолированный доступ |
| Мониторинг | Grafana | Дашборды для клиентов |
| Автоматизация | Ansible | Деплой и управление нодами |
