## Обзор

Платформа предоставляет клиентам управляемое окружение для запуска контейнерных приложений. Каждый клиент получает изолированный namespace в Kubernetes с выделенными ресурсами, доменом и SSL-сертификатом.

---

## Порог входа

**Оценка: низкий**

| Что нужно | Детали |
|-----------|--------|
| Железо | Уже есть: MC1 x12, HC1, RPi4 |
| ПО | K3s, Longhorn, Traefik — open source, бесплатно |
| Знания | Kubernetes, Linux, базовый networking |
| Время до MVP | 2–4 недели |
| Стартовый капитал | Минимальный — только железо и интернет-канал |

Это самый быстрый путь к первым клиентам и первым деньгам. Не требует сложной разработки — достаточно настроить инфраструктуру и выставить тарифы.

## Маржинальность

**Оценка: средняя**

| Статья | Детали |
|--------|--------|
| CAPEX | Железо (уже куплено) |
| OPEX | Электричество (~150–300 Вт постоянно), интернет-канал, домен |
| Средний чек | $10–50/мес за клиента (namespace S/M/L) |
| Точка безубыточности | ~15–30 активных клиентов |
| Потолок маржи | Ограничен числом нод и пропускной способностью сети |

Маржа средняя из-за конкуренции с дешёвым VPS-хостингом. Дифференциация — ARM-архитектура, зелёная энергоэффективность, личный саппорт.

## Целевой клиент

**Сегмент: стартапы и разработчики**

| Портрет | Детали |
|---------|--------|
| Кто | Инди-разработчики, небольшие команды (2–10 чел), стартапы на ранней стадии |
| Задача | Быстро задеплоить MVP, не тратить время на DevOps |
| Боль | AWS/GCP слишком дорого и сложно для старта |
| Платит | $10–50/мес, легко конвертируется |
| Канал | GitHub, Reddit, HackerNews, Telegram-сообщества разработчиков |

**Дополнительный сегмент:** образовательные проекты, pet-projects, open source — платят меньше, но дают репутацию и органический трафик.

**Оценка: средняя**

| Конкурент | Цена | Слабость |
|-----------|------|----------|
| DigitalOcean / Hetzner | $5–20/мес | Безликий, нет персонального саппорта |

| AWS ECS / EKS | $50+/мес | Сложно, дорого для малого проекта |
| Vercel / Netlify | $0–20/мес | Только фронтенд/JAMstack |

**Наши преимущества:**
- ARM-архитектура → ниже энергопотребление → ниже цена
- Персональный саппорт
- Возможность кастомных конфигураций
- "Зелёный" хостинг как маркетинговый аргумент

## Архитектура

```
Internet
    │
    ▼
[RPi4 4GB] ── Control Plane (K3s Server, Traefik Ingress, MetalLB)
    │
[1Gb Switch]
    ├── [MC1 #01] ── 4x Worker Nodes
    ├── [MC1 #02] ── 4x Worker Nodes
    ├── ...
    ├── [MC1 #12] ── 4x Worker Nodes  (48 workers total)
    └── [HC1]     ── Storage Node (Longhorn, NFS)

Клиент A → namespace-a (quota: 2CPU, 2Gi RAM, 10Gi storage)
Клиент B → namespace-b (quota: 4CPU, 4Gi RAM, 20Gi storage)
```

**Сетевая топология:**
- Внешний IP → RPi4 (edge router / ingress)
- Внутренняя сеть: 192.168.1.0/24
- VLAN разделение: management / data plane

## Стек технологий

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Оркестрация | K3s | Lightweight Kubernetes для ARM |
| Ingress | Traefik | Роутинг, SSL termination |
| LoadBalancer | MetalLB | Внешние IP для сервисов |
| Хранилище | Longhorn | Реплицированное блочное хранилище |
| Мониторинг | Prometheus + Grafana | Метрики нод и namespace |
| Логи | Loki + Promtail | Централизованные логи |
| CI/CD | Gitea + Drone CI | Self-hosted Git и пайплайны |
| Автоматизация | Ansible | Деплой и конфигурация нод |
| UI для клиентов | Portainer | Управление контейнерами |
